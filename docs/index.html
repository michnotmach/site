build and run

You need a Linux host with GNU Make, GCC, binutils, NASM, Python 3, qemu-system-x86, OVMF UEFI firmware, and coreutils. The build does not fetch anything from the network. 

sudo apt update
sudo apt install build-essential gcc-multilib binutils nasm python3 qemu-system-x86 ovmf coreutils

git clone --recurse-submodules https://github.com/ukdaemonz/mich-core.git
cd mich-core
make -j2
make run64

If you cloned without --recurse-submodules, run git submodule update --init so src/user64 (mich-userkit) is populated. Serial console output goes to stdio.

system calls (x86-64)

Mich enters the kernel through the x86-64 syscall instruction. The full list is tracked in docs/syscalls.md and dispatched in src/arch/x86_64/kernel/syscall_dispatch.c.

  • RAX holds the syscall number on entry and the return value on exit
  • arguments go in RDI, RSI, RDX
  • calls fail closed: bad pointers, missing capabilities, or missing handle rights return an error before touching state

crypto policy

The kernel only keeps crypto primitives that cannot live in userspace:

  • ChaCha20 DRBG for kernel entropy and getrandom
  • SipHash-2-4 keyed at boot for TCP Initial Sequence Numbers
  • CRC32C for adytumfs superblock and block checksums

No TLS, no X.509, and no public-key code in ring 0. Link your TLS library in userspace.
