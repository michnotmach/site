mich 0.2.0 - JOVIS (2026-09-29)

tag: v0.2.0 · commit: 483d79b · BSD 2-Clause

notes

  • userspace driver supervisor with 32-tick graceful stop, PCI FLR reset policy, and fault quarantine
  • mich-userkit submodule under src/user64 for init, static libc, POSIX headers, and the virtio-net capsule
  • Intel VT-d and AMD-Vi IOMMU page tables, coherent DMA windows, and QEMU EDU forbidden-DMA test
  • full custom network stack: packet pools, ARP, IPv4, DHCPv4, IPv6, NDP/SLAAC, UDP/UDPv6, and TCP stream sockets
  • post-0.2.0 trunk changes on main:
    • relicensed from GPLv3 to BSD 2-Clause
    • adytumfs v3 tree node format and reference-held node naming
    • ordered SMP locking across task pool, FD table, and pipes
    • controlling terminal and canonical console line discipline
