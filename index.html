Zero lines of Linux, BSD, XNU, or Mach source code in the default install!

Mich Core is an experimental modular hybrid kernel for x86-64, written from scratch in C and assembly under the BSD 2-Clause License. It is unfinished. The disk images are test targets, not an installable distribution. Boot it at your own risk.

what works right now

  • typed kernel objects and 24-bit generation-counted handles
  • Ring 3 userspace driver domains with crash recovery and PCI quarantine
  • Intel VT-d and AMD-Vi IOMMU DMA translation
  • bounded in-kernel VFS (ramfs, bootfs, and persistent adytumfs v3)
  • static x86-64 POSIX source profile with pledge, unveil, and job control
  • in-house network stack (userspace virtio-net capsule, DHCPv4, IPv4/IPv6, SLAAC, UDP/UDPv6, TCP stream sockets)
  • SMP bring-up, per-CPU state, reschedule and TLB shootdown IPIs

kernel rules

  • scheduling, memory ownership, IPC, capabilities, and hardware resource control stay inside the kernel core
  • new hardware drivers start in userspace
  • a dead driver must not take down unrelated processes
  • teardown masks IRQs, disables bus mastering, revokes mappings, invalidates handles, and runs PCI reset policy before restart
  • failed teardown quarantines the device until reboot
  • packet paths run on preallocated pools and bounded rings with zero per-packet allocations
  • QEMU cycle numbers are regression checks, not wire throughput claims

source & contact

The kernel tree lives at github.com/ukdaemonz/mich-core. Userspace init, static libc, POSIX headers, and driver capsules live in mich-userkit.
